# Modern Responsive Website

A modern, responsive, and interactive website built using **HTML, CSS, and JavaScript**. The project focuses on a clean user interface, responsive design, and smooth interactions across different screen sizes.

# Live Demo
https://soniyashaik29.github.io/Rock-Paper-Scissor-AI-VS-Human-/

## 🚀 Features

* 📱 Fully responsive design
* 🎨 Clean and modern user interface
* ⚡ Interactive elements using JavaScript
* 🌐 Built with standard HTML, CSS, and JavaScript
* 💻 Works on desktop, tablet, and mobile devices
* ✨ Smooth and user-friendly experience

## 🛠️ Technologies Used

* **HTML5** – Website structure and content
* **CSS3** – Styling, layout, animations, and responsive design
* **JavaScript** – Interactivity and dynamic functionality

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/soniyashaik29/Rock-Paper-Scissor-(AI-VS-Human).git
```

2. Open the project folder.

3. Open `index.html` in your web browser.

That's it! No additional installation or dependencies are required.
